**15:49** — Added `snap_boxes_to_gutters()` to `src/comicreel/stages/panel_detection.py` — expands each of a box's 4 edges outward to the nearest genuine whitespace gutter (contiguous run of background-brightness pixels, min width configurable, default 8px), bounded by a max search distance (default 8% of the page dimension) so it can't cross into a neighboring panel. Leaves already-correct boxes and boxes with no confident nearby gutter unchanged.

**15:50** — Wired it into `MagiPanelDetector.run()`, on by default via a new `options.snap_to_gutters` config flag (default `true`). Not applied to the CV heuristic backend, since its boxes are already built directly from gutter detection.
